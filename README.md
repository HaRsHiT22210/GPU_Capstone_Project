# GPU Capstone Project: Image Grayscale and Histogram using CUDA

## Description
This project demonstrates GPU acceleration using CUDA to:
- Convert color images to grayscale.
- Compute image histograms.

The project uses NVIDIA CUDA for parallel image processing and OpenCV for image I/O.
